# CallALL — зазывала без рекламы

## 1. Создай бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → имя `CallALL`, юзернейм например `CallALL_group_bot`.
2. Скопируй токен.
3. **Важно:** `/setprivacy` → выбери бота → **Disable**. Иначе бот не видит обычные сообщения и не сможет запоминать участников и понимать «каллалл» без слэша.
   (Если privacy включили уже после добавления в группу — удали бота из группы и добавь заново.)

## 2. Запусти
```bash
cd callall
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и вставь свой токен в .env
python bot.py
```
Бот работает, пока запущен скрипт. Чтобы он работал круглосуточно — запусти его на сервере (любой дешёвый VPS, Raspberry Pi и т.п.).

## 3. Добавь в группу
Добавь бота в чат одногруппников и (желательно) сделай админом. Попроси всех написать любое сообщение —
так бот их запомнит (Telegram не даёт ботам список участников).

## Команды
| Команда | Алиас | Что делает |
|---|---|---|
| /all | каллалл | позвать всех |
| /call | калл | позвать актив (кто писал за N дней, N в настройках) |
| /callone | каллван | позвать всех по одному сообщению на человека |
| /stop | стоп | остановить созыв |
| /unreg | анрег | выйти из призыва |
| /reg | рег | вернуться в призыв |
| /unregs | анрегс | список анрегнутых |
| /settings | — | настройки (только админы): период актива, упоминаний в сообщении, кто может звать |
| /language | — | язык чата (ru/en) |
| /me | ми | твой позывной |
| /bigme | бигми | позывной крупно |
| /changeme | чанджми | сменить позывной: `чанджми 🦄` (без аргумента — случайный) |

К созыву можно дописать текст: `каллалл пара через 5 минут`.

Данные хранятся в файле `callall.db` рядом с ботом.
